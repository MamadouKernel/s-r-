Maquette à valider — pas encore le vrai programme. Quatre étapes du même écran : choisir le fichier, voir les lignes à corriger, voir que tout est juste, lire le résultat. Cliquez sur les onglets.

On y arrive depuis Gestion → Produits → « Importer depuis Excel » (visible pour le propriétaire et le gérant). En trois gestes : télécharger le modèle, le remplir, le choisir.

Importer des produits depuis Excel

1

Téléchargez le modèle et remplissez-le dans Excel : une ligne par produit, ou par format (5 kg, 25 kg…).

Comment remplir le fichier ?

• Plusieurs lignes avec le même nom forment un seul produit en plusieurs formats.

• Prix et stock : des nombres entiers, sans virgule. Le prix de vente est obligatoire.

• Le « Stock de départ » est ce que vous avez aujourd'hui en rayon.

• Un produit déjà dans votre catalogue n'est jamais modifié.

2

Choisissez votre fichier rempli (.xlsx, 2 Mo et 2 000 lignes au plus).

Rien n'est enregistré à cette étape : nous vérifions d'abord votre fichier.

Messages prévus si le fichier n'est pas le bon : « Ce fichier n'est pas un classeur Excel (.xlsx). Utilisez le modèle à télécharger. » · « Ce fichier est trop lourd (2 Mo au plus). » · « Il manque la colonne « Prix de vente ». »

Le fichier est vérifié tout de suite. S'il y a une seule ligne à corriger, rien n'est importé : on corrige dans Excel, on rechoisit le fichier, et tout passe d'un coup. Toutes les erreurs sont listées ensemble, avec le numéro de ligne tel qu'Excel l'affiche.
